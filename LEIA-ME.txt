ESTUDA SUZANO 2.0 | GITHUB PAGES

Novidades
- Visual novo, com painel de progresso, modo escuro automático e versão para celular.
- Aba Videoaulas: os 64 temas do conteúdo programático do Edital 02/2026 viraram pendências,
  cada um com videoaulas selecionadas, botão "buscar mais vídeos" e "marcar como estudado".
- Login com Google. Quem entra fica "aguardando" até o administrador liberar o acesso completo.
  Antes disso a pessoa vê só a amostra (2 temas e 10 questões) e o aviso para falar com o admin.
- Progresso (temas, respostas e simulados) salvo na conta, em qualquer aparelho.
- Aba Admin para liberar, bloquear e acompanhar o progresso de cada pessoa.

Publicação
1. GitHub > Settings > Pages > Deploy from a branch > main > /(root). (Igual antes.)
2. Configure o login seguindo CONFIGURAR-LOGIN.md (Firebase, ~10 minutos).
   Enquanto não configurar, o site mostra a tela "Quase lá".

Arquivos
- index.html, assets/ ........ site gerado (não editar à mão)
- firebase-config.js ......... chaves do Firebase, e-mails de admin e contato (editar no GitHub)
- firestore.rules ............ regras de segurança (colar no Firebase)
- app/ ....................... código-fonte React (npm run build regenera o site)
- Questoes-para-imprimir.html, Gabarito-comentado.html, Acervo-e-fontes.html ... material para imprimir

Conteúdo: 250 questões com gabarito comentado (40 avançadas), 64 temas com videoaulas,
simulados de 34 questões (8 Português, 8 Matemática, 8 Legislação, 10 Específicos).
